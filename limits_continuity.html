Limits & Continuity

What happens to $f(x)$ as $x$ gets close to some target? That question — the limit — is the foundation of calculus. Continuity asks: does the function's value at the target match what the limit predicts?

1 What is a limit?

We write $\displaystyle\lim_{x \to a} f(x) = L$ when $f(x)$ gets arbitrarily close to $L$ as $x$ approaches $a$ — without caring what (if anything) happens at $x = a$ itself. Watch the two dots approach $x = a$ from the left and right. If both $f$-values converge to the same number, the limit exists.

  1. For $\sin(x)/x$: the function is undefined at 0, yet the limit is 1. How can a function "approach" a value it never reaches?
  2. For $|x|/x$: both one-sided limits exist. Why doesn't the two-sided limit exist?

  4. For $x\sin(1/x)$: the oscillation is still there, but now it's squeezed to 0. What changed?

2 The ε–δ definition

How do we make "gets arbitrarily close" precise? We say $\displaystyle\lim_{x\to a}f(x) = L$ if: for every $\varepsilon > 0$ there exists $\delta > 0$ such that $0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon$.

Translation: you name any tolerance $\varepsilon$ (the green band). I must find a window $\delta$ (the blue band) around $a$ so the curve stays inside your tolerance. Try it: pick $\varepsilon$, then adjust $\delta$.

The game metaphor

Think of ε–δ as a two-player game. Player 1 (the challenger) picks any $\varepsilon > 0$, no matter how small. Player 2 (the prover) must respond with a $\delta > 0$ that works. If Player 2 can always win, the limit is $L$. If there's some $\varepsilon$ where no $\delta$ works, the limit is not $L$.

Questions to ask the student
  1. For $f(x)=2x+1$ at $a=1$: if $\varepsilon = 0.5$, what is the largest $\delta$ that works? Can you find a formula relating $\delta$ to $\varepsilon$?
  2. For $f(x)=x^2$ at $a=2$: does $\delta = \varepsilon$ always work? Why not? (Hint: the slope matters.)
  3. Why does the definition say $0 < |x-a|$ rather than just $|x-a| < \delta$? What would change?

3 Continuity: three conditions

A function is continuous at $x = a$ when three things all hold. Toggle each condition below to see what happens when it fails.

① $f(a)$ is defined ✓
② $\displaystyle\lim_{x\to a}f(x)$ exists ✓
③ $\displaystyle\lim_{x\to a}f(x) = f(a)$ ✓

Why all three?

Each condition rules out a different kind of "surprise":

① rules out holes (the function simply isn't defined there).
② rules out jumps and wild oscillation (the left and right limits don't match).
③ rules out "misplaced" points (the function is defined, the limit exists, but they disagree).

When all three hold, $f$ has no surprises at $a$: the value you'd predict from nearby points is exactly the value you get.

Questions to ask the student
  1. Condition ③ is redundant if ① or ② fails. Why do we still list all three?
  2. Can ② fail while ① holds? Give an example.
  3. If only ③ fails (① and ② hold), can you "fix" the function by redefining $f(a)$?

4 The discontinuity zoo

When continuity fails, the type of discontinuity tells you what went wrong. Click each card to see the example.

Removable

The limit exists, but $f(a)$ is missing or wrong. A single-point "hole" you can fill in.

Jump

Both one-sided limits exist but are different. The function "jumps" across a gap.

Infinite

The function blows up to $\pm\infty$. A vertical asymptote.

Oscillating

The function oscillates too wildly for a limit to exist at all.

Questions to ask the student
  1. Which discontinuity type is the "mildest"? (Removable — you can fix it by defining or redefining one point.)
  2. At a jump discontinuity, how many one-sided limits exist? (Two, and both are finite, but they're not equal.)
  3. Is $f(x) = \sin(1/x)$ at $x=0$ a removable discontinuity? (No — no limit exists, so there's no value to "fill in.")

5 The Intermediate Value Theorem

If $f$ is continuous on $[a,\,b]$ and $k$ is any value between $f(a)$ and $f(b)$, then there is at least one $c \in (a,b)$ with $f(c) = k$. In plain language: a continuous curve that starts below $k$ and ends above it must cross $k$ somewhere.

Why continuity is essential

Remove continuity and the theorem fails. A jump function can go from $-1$ to $+1$ without ever hitting 0. The IVT is the reason you can trust root-finding algorithms like bisection: if $f(a)$ and $f(b)$ have opposite signs and $f$ is continuous, there must be a root between them.

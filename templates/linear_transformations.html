Linear Transformations

The main idea: an invertible matrix doesn't change the space. It changes the coordinates we use to describe it.

1 · Two readings of one matrix 3D · The same idea in space 2 · The best basis: eigenvectors 3 · PCA: change of basis on data 4 · Where this shows up in ML

1 Two readings of one matrix

A $2\times2$ matrix $A$ is fully described by its columns, which are where the basis vectors land: $A\hat\imath = a_1$ and $A\hat\jmath = a_2$. For any vector, $$A\begin{bmatrix}x\\y\end{bmatrix} = x\,a_1 + y\,a_2 .$$ You can read this equation two ways. The pictures below show both, for the same matrix and the same vector.

Why the two readings are the same thing

The numbers $(x, y)$ are the point's coordinates in the new basis $\{a_1, a_2\}$. Multiplying by $A$ converts them to coordinates in the standard basis. $A^{-1}$ goes back the other way.

$$\underbrace{\begin{bmatrix}x\\y\end{bmatrix}}_{\text{new-basis coords}} \;\xrightarrow{\;A\;}\; \underbrace{Av}_{\text{standard coords}} \qquad\qquad Av \;\xrightarrow{\;A^{-1}\;}\; \begin{bmatrix}x\\y\end{bmatrix}$$

When is $A$ invertible? Exactly when its columns $a_1, a_2$ form a basis, i.e. when they are not parallel ($\det A \neq 0$). Then every point has exactly one name in the new coordinates. Try the Singular preset: the grid collapses onto a line, many points get the same image, and no inverse can recover them.

The shaded cell is the image of the unit square. Its signed area is $\det A$, the factor by which areas get scaled. A negative value means orientation flips, as in a mirror.

Questions to ask the student
  1. Set $A$ to the Identity. What does "coordinates in the new basis" mean now?
  2. With Stretch: the point's new-basis coordinates stay $(x,y)$, but its standard coordinates change. Why?
  3. Drag $a_2$ until it lies on top of $a_1$. What happens to $\det A$? Which points can no longer be described?
  4. Rotation by 30°: is that "moving the space", or "turning your head"? (Both readings work.)

3D The same idea in three dimensions

Nothing changes in 3D except the count. A $3\times3$ matrix has three columns: where $\hat\imath, \hat\jmath, \hat k$ land. $$A\begin{bmatrix}x\\y\\z\end{bmatrix} = x\,a_1 + y\,a_2 + z\,a_3$$ The unit cube becomes a slanted box (a parallelepiped) with volume $|\det A|$. $A$ is invertible exactly when $a_1, a_2, a_3$ don't all lie in one plane. Then they form a basis of space, and $(x,y,z)$ is just the point's address in that basis.

Questions to ask the student
  1. Flatten to plane: $a_3 = a_1 + a_2$. Which points of space can still be reached? What happened to the volume?
  2. Crush to line: all three columns point the same way. What is the rank, and how much information survives?
  3. Mirror: the volume stays 1 but $\det A = -1$. What does the sign mean? (Right-handed becomes left-handed.)
  4. Rotate about z: which vector doesn't move at all? (That's an eigenvector with eigenvalue 1.)
  5. ML link: an embedding layer projecting 768 → 3 dimensions behaves like Flatten. It can't be undone, which is why we choose the projection carefully (PCA, learned weights).

2 Same transformation, different basis: $B = P^{-1}AP$

If we can choose any basis, which one makes $A$ simplest? Pick a basis $P$ (its columns are the new basis vectors). In that basis the same transformation is written $B = P^{-1} A P$: convert to standard coordinates ($P$), apply $A$, then convert back ($P^{-1}$). $A$ and $B$ describe the same geometry, only the numbers differ.

Questions to ask the student
  1. In the eigenbasis, $B$ is diagonal. What do the diagonal entries mean geometrically?
  2. Why is the shear "stuck"? (It has only one eigen-direction, so there aren't enough eigenvectors to form a basis.)
  3. Rotation has no real eigenvectors. Why does no line through the origin stay on itself?
  4. For the symmetric matrix, notice that the eigenvectors are perpendicular. That is always true for symmetric matrices, and it is the reason PCA works (next section).

3 PCA is a change of basis on data

Data features are coordinates. Height and weight are correlated: knowing one tells you something about the other. The covariance matrix $\Sigma$ is symmetric, so it has a perpendicular eigenbasis $V$. Re-expressing each point as $z = V^{\top}x$ is a rotation of the coordinate axes. In the new coordinates the features are uncorrelated: $\operatorname{Cov}(z) = V^{\top}\Sigma V$ is diagonal. This is Section 2 again, with $P = V$.

Questions to ask the student
  1. Watch the off-diagonal entry of the covariance as $t \to 1$. What does it reaching 0 mean in words?
  2. The rotation is invertible, so no information is lost. Where exactly does information get lost in PCA? (When we tick "Drop PC2", a projection with $\det = 0$, like the Singular preset in Section 1.)
  3. Whitening is another invertible change of basis. Why might a model train faster on whitened inputs?
  4. Set elongation to 1 (a round cloud). Why is the PCA direction now meaningless?

4 Where "it's just a change of basis" shows up in ML

Linear layers can't create information

A layer $h = Wx$ with square, invertible $W$ only re-describes the input in new coordinates. Nothing is created and nothing is lost. Stacking linear layers gives one linear layer ($W_2W_1x$). The nonlinearity between them is what adds expressive power.

Standardization & whitening

Scaling features, decorrelating them, or applying PCA are all invertible changes of basis applied before training. The model sees the same information, but the loss surface becomes rounder, so gradient descent converges faster.

The basis of an embedding is arbitrary

For an orthogonal $Q$ (a rotation), $(Qx)\cdot(Qy) = x\cdot y$. Rotating every embedding leaves all dot products, distances and attention scores ($q^{\top}k$) unchanged. This is why a single neuron or embedding dimension usually has no fixed meaning: the network could equally well have learned a rotated basis.

Normalizing flows

These generative models chain invertible maps $z = f(x)$, so every data point has a unique latent code and can be recovered. Densities transform with the determinant (area scaling, as in Section 1): $p_x(x) = p_z(f(x))\,|\det J_f(x)|$.

Conditioning & near-singular matrices

When $\det A \approx 0$, the basis vectors are nearly parallel. Tiny changes in $Av$ then cause huge changes in the recovered coordinates $A^{-1}(Av)$. That instability shows up as ill-conditioned least-squares problems, exploding gradients and the need for regularization ($A^{\top}A + \lambda I$).

Eigen/SVD everywhere

The SVD $A = U\Sigma V^{\top}$ says that every matrix becomes a pure stretch once you pick the right bases: rotate ($V^{\top}$), stretch ($\Sigma$), rotate ($U$). This idea underlies PCA, low-rank compression (LoRA), recommender systems and spectral clustering.
